# Rashmi Rani — Portfolio

Responsive Android / Kotlin Multiplatform developer portfolio built with React 18 and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Production build

```bash
npm run build
npm run preview
```

## Responsive behavior

The portfolio is optimized for mobile phones (including 320px widths), tablets and desktop screens. Navigation, hero content, buttons, statistics, project cards, code blocks, experience, skills, education and footer reflow at responsive breakpoints.

## Main files

- `src/Portfolio.jsx` — portfolio UI and responsive component styling
- `src/index.css` — global responsive safety and Tailwind setup
- `src/App.jsx` — app entry component
- `src/main.jsx` — React entry point
- `public/favicon.svg` — favicon
